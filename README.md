# PR Mini-Pilot

Reproducible small-scale pilot for fixed-backbone protein/RNA inverse folding and joint protein–RNA co-design.

This repository is being initialized with a strict end-to-end experimental framework covering: data freezing and auditing, ProteinMPNN protein baseline, MPNN-fixbb RNA baseline, DM-ICF joint model training from scratch, held-out 100-complex evaluation, ablations, robustness tests, partner-dependence tests, statistical analysis, and reproducibility manifests.

See `docs/EXPERIMENT_SPEC.md` after the framework commit for the complete protocol.
